# 🐾 Nina's Pet Care

O **Nina's Pet Care** é um projeto de um site voltado para serviços de cuidados com pets.

A ideia surgiu a partir da Nina, minha cachorrinha, que serviu de inspiração tanto para a identidade do projeto quanto para a proposta do site. O objetivo foi desenvolver uma experiência simples, acolhedora e fácil de navegar, simulando o site de uma empresa real de cuidados para animais.

Este projeto também faz parte do meu portfólio e foi desenvolvido para colocar em prática meus conhecimentos em **HTML, CSS e JavaScript**, principalmente estruturação de páginas, estilização, responsividade e interações com o usuário.

## 🐶 Sobre o projeto

O site apresenta os principais serviços oferecidos pela Nina's Pet Care e permite que o usuário navegue entre diferentes páginas para conhecer melhor a empresa e entrar em contato.

Entre os serviços apresentados estão:

- Banho e tosa
- Passeios
- Dog Care
- Hospedagem

O projeto foi pensado tanto para **desktop quanto para dispositivos móveis**, adaptando a navegação e o conteúdo para diferentes tamanhos de tela.

## 📄 Páginas

O site é dividido em quatro páginas principais:

### 🏠 Home
Apresenta a Nina's Pet Care, os principais serviços, avaliações, funcionamento e área de atendimento.

### 🐾 Sobre
Conta um pouco da história do projeto e da inspiração por trás da Nina's Pet Care.

### 🛁 Serviços
Apresenta de forma mais detalhada os serviços disponíveis e permite acessar diretamente cada tipo de cuidado.

### 📞 Contato
Reúne os canais de contato da empresa, incluindo WhatsApp, Instagram e e-mail.

## 💻 Tecnologias utilizadas

O projeto foi desenvolvido utilizando:

- HTML5

- JavaScript

## 📱 Responsividade

O site possui layout responsivo para diferentes tamanhos de tela.

Na versão mobile foram feitas adaptações como:

- Menu hambúrguer
- Reorganização das seções
- Ajustes de tipografia
- Cards adaptados para telas menores
- Imagens responsivas
- Ajustes específicos de espaçamento e navegação

## 🎯 Objetivo

Mais do que criar apenas uma página visual, o objetivo deste projeto foi praticar a construção de um site completo desde a estrutura inicial até os detalhes finais de responsividade.

Durante o desenvolvimento trabalhei conceitos como:

- HTML semântico
- Organização e reutilização de CSS
- Flexbox e Grid
- Media Queries
- Manipulação básica do DOM com JavaScript
- Navegação por âncoras
- Responsividade
- Organização de arquivos
- Git e GitHub
- Otimização de imagens para web
